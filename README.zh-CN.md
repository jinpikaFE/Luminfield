# Luminfield

简体中文 | [English](README.md)

Luminfield 是一款使用 Godot 4.7.1 .NET 与 C# 制作的原创双语农场生活
RPG 垂直切片。项目没有使用《星露谷物语》或其他商业游戏的素材、角色、
地图、文本、音乐及代码。

## 可玩内容

当前版本包含以下完整流程：

1. 与米菈交谈，领取星芽莓种子。
2. 开垦至少三块农田。
3. 种下并浇灌三株星芽莓。
4. 在小屋睡眠两次，让已浇水的作物成长。
5. 收获三株成熟的星芽莓。
6. 返回米菈处交付作物并完成试玩。

完成教程后可以继续经营：

- 在右侧的暮光商亭购买二十种原创作物的种子；芽辉季、雨幕季和星熟季各有
  四种限定作物，原有八种为兼容教程与旧存档继续支持跨季种植。
- 在农场商亭购买月梅树苗，种在家园开阔空地；成熟后反复采摘月梅，并用
  月梅、微光木和晶辉碎片制作辉巢，在成熟果树附近过夜酿出星蜜。
- 出售星芽莓、月辉根、云纹叶、微光豆、余烬铃、棱晶穗、露珠瓜、
  暮铃花、曦绫花、辉荚藤、雾歌薄荷、彗纹薯及价值更高的加工品，赚取微光币。
- 让三台固定加工机独立运作，并单独领取或原子领取全部已完成产物。
- 用收入购买更多种子，形成“种植 → 加工 → 出售 → 扩种”的持续循环。

原有 48×32 农场现已通过南侧发光石阶连接到 192×128 格的大世界。扩建后的
中央微光城位于地图中心，以四向放射道路连接家园农场、低语林地、星落草甸、
晶辉谷、月水湿地与星落遗迹；从城区出发前往任一区域都不再需要绕行地图边缘。
地图按 32×32 格区块加载，只保留玩家周围 3×3 个区块，因此镜头可以连续跨区
移动，而不必一次创建整张地图。

外围区域已从高密度随机重复物件改为低密度环境层、34 处固定构图物件和 8 处
大型原创景观。林地月根树丛、草甸月花环、晶谷阶梯晶脊、湿地栈桥岛与遗迹断柱廊
各自形成独立视觉记忆点；道路、碰撞、资源、NPC 和存档仍由领域规则持有。

右上角迷你地图会随移动揭开已探索区块，隐藏未知区域，并标记已发现地标。
探索迷雾与区块记录会和常规存档一起保存。

## 七日天气、星辉货箱与二十种作物

- 每七天组成一周；芽辉季、雨幕季、星熟季和长夜季各 14 天，共同组成
  56 天一年。HUD 同时显示当前季节名、季节日、原创星期名、当前天气和次日预报。
- 当前天气包含晴朗、小雨、星尘风和长夜雪；小雨会自动浇灌已开垦土壤，星尘风、
  雨天和长夜雪都有独立环境表现。长夜季第 1、5、8、12 日自然降雪，户外移动
  降低 15%，但不会自动浇水；小屋、温室与村庄室内保持正常速度且不绘制雪层。
- 家园左侧新增星辉货箱。选择“手”靠近后，可以把收成、加工品和采集物放入
  货箱，也可以在睡前取回。
- 睡眠时货箱按稳定物品售价统一结算，微光币随后入账，并显示逐项收益、总收入、
  新星期与天气预报。
- 大世界水晶采集后隔 2 天再生，树木隔 7 天再生；夜间总结会提示当天重新
  生长的资源数量。采集日期与再生周期会随存档恢复。

## 工具与背包

8 格快捷栏和背包现在是两个层次：

- 第 1 格固定为“手”，用于收获成熟作物和查看地标。
- 星尘铲负责开垦农田，也能挖掘大世界里的晶体。
- 月纹柴刀负责砍伐可采集树木。
- 凝露壶最多携带 12 份水。
- 面向池塘、溪流或湿地水面使用汲水桶，可以补满凝露壶。
- 完整背包共有 24 格，按 `B` 或 `Tab` 打开；最上方 8 格就是快捷栏。

目标区会识别前方物件：青绿色轮廓表示可以按 `E` 执行，暖金色表示需要切换
工具，玫红色表示体力、水量、种子或背包容量不足。树、晶体、水面、作物、NPC、
门、商亭、加工机和床都会高亮真实对象范围，而不是只显示一个无含义的地面框。

树木产出微光木，晶簇产出晶辉碎片。采集后的节点会暂时从地图消失并变为
可通行；水晶隔 2 天、树木隔 7 天重新生长。旧存档中的永久移除节点会从读档日
开始进入安全的再生周期，`hoe` 也会自动迁移为新的固定工具顺序，不会丢失
已有种子和收成。

## 开发试玩场景

开发启动参数按优先级集中注册在
[`PlaytestScenarioRegistry.cs`](src/Game/PlaytestScenarioRegistry.cs)。注册器
保持精确、区分大小写的匹配；同时提供多个已知参数时，优先选择注册顺序靠前的
场景；没有命中试玩参数时，游戏仍按正常流程停留在标题页。

`Main.CreatePlaytestScenarioRegistry()` 负责把每个场景 ID 绑定到对应的准备方法。
新增场景时，在注册器中补充 ID 与参数，再在 `Main` 中增加准备方法绑定即可。
聚焦测试会锁定已知参数清单、唯一性、优先级与正常回退行为。

使用 `--playtest-liora-event-one`、`--playtest-liora-event-two`、
`--playtest-tavi-event-one` 与 `--playtest-tavi-event-two` 可以直接在月辉
档案馆或月石工坊打开对应的两阶段事件；这些参数保持既有注册顺序优先级，
并可配合 `--capture-playtest=<路径>` 进行确定性视觉验收。

使用 `--playtest-nemi-event-one` 与 `--playtest-nemi-event-two` 可在奈米普通日
14:00 的村庄路线直接打开两阶段友情事件；使用 `--playtest-starlight-post-door`、
`--playtest-starlight-post` 与 `--playtest-starlight-post-nemi` 可检查第五栋建筑
外门、只读路线分拣台和奈米室内工作位置；使用
`--playtest-starlight-post-wrong-tool` 可验证完整柜台轮廓显示暖金色工具不匹配状态。

使用 `--playtest-kael-event-one` 与 `--playtest-kael-event-two` 可在凯尔普通日
14:00 的真实村庄投影直接打开两阶段友情事件；使用
`--playtest-starfall-watch-door`、`--playtest-starfall-watch` 与
`--playtest-starfall-watch-kael` 可检查第六栋建筑外门、只读封印巡路台和
凯尔室内工作位置；使用 `--playtest-starfall-watch-wrong-tool` 可验证完整
巡路台轮廓显示暖金色工具不匹配状态。

使用 `--playtest-emporium-door`、`--playtest-emporium` 与

## 本地工具链

项目固定使用以下版本：

- Godot 4.7.1 .NET
- .NET SDK 10.0.302
- 项目目标框架 `net8.0`

当前工作区的工具安装在仓库外部：
`$HOME/.codex/tools/luminfield/`。

macOS 请运行：

```bash
./scripts/open_editor_macos.command
```

该启动器会为 Godot 注入项目专用的 `DOTNET_ROOT`。不要直接从 Finder 双击
原始 `Godot_mono.app`，否则 Finder 不会继承本地 SDK 路径，编辑器会提示
无法加载 `hostfxr`。

```bash
export LUMINFIELD_TOOLS="$HOME/.codex/tools/luminfield"
export DOTNET_ROOT="$LUMINFIELD_TOOLS/dotnet"
export PATH="$DOTNET_ROOT:$PATH"

"$DOTNET_ROOT/dotnet" build
"$LUMINFIELD_TOOLS/godot/Godot_mono.app/Contents/MacOS/Godot" \
  --path "$(pwd)" --editor
```
