# Luminfield 原创生成美术

本目录资产由 OpenAI 内置图像生成工具为 Luminfield 单独生成，参考图只用于确定暮色、发光植物、密集环境层次和像素画方向；没有复制参考游戏的角色、地图或现成素材。

- `farm_twilight_backdrop.png`：1536×1024 原创暮色农场全景，在 Godot 中以 0.5 倍显示为 768×512 世界背景。
- `item_icons_final.png`：透明背景的 3×2 原创物品图集，包含锄头、浇水壶、两类种子袋、星芽莓和月辉根。
- `cottage_twilight_interior.png`：1536×1024 原创魔法小屋内景，运行时裁切为 640×360 可玩区域。
- `character_directions_chroma.png`：玩家与米菈的 4 方向原创人物图集；Godot 使用红色色键材质透明化，避免破坏肤色和暖金细节。
- `player_walk_cycle_chroma.png`：玩家前、后、左、右四方向的两帧交替步态图集；移动时切换左右脚、手臂与挎包摆动，停止后恢复站立图集。
- `crop_stages_chroma.png`：星芽莓与月辉根各 4 个成长阶段的原创作物图集；由稳定作物 ID 和成长阶段索引选择。

- `moonstone_path_tiles.png`：2×2 的原创月石道路地板变体，运行时按世界格哈希选择并缩放为 16×16 像素，替换旧的程序化砖块道路。

`item_icons_chroma.png` 是去背景前的红底原稿；`item_icons.png` 与 `item_icons_clean.png` 是透明化调试版本，不被运行时加载。
