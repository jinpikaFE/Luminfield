# Luminfield 原创生成美术

本目录资产由 OpenAI 内置图像生成工具为 Luminfield 单独生成，参考图只用于确定暮色、发光植物、密集环境层次和像素画方向；没有复制参考游戏的角色、地图或现成素材。

本文中的文件路径均相对于 `assets/generated/`。目录根只保留本说明，PNG 与对应 `.png.import` 必须归入职责目录。

## 目录分类

| 目录 | 职责 |
| --- | --- |
| `activities/` | 战斗、节庆、钓鱼与采矿 |
| `animals/` | 畜牧共用资源与各物种角色、设施、内景 |
| `characters/` | 玩家与 NPC |
| `farming/` | 作物、采集、果园与农业放置物 |
| `features/` | 委托、施工、经济主循环、邮件、加工、关系、星灯与储物功能点 |
| `locations/` | 小屋与村庄等可进入地点 |
| `ui/` | 跨场景物品和工具图标 |
| `world/` | 家园、大世界与天气 |
| `legacy/` | 当前运行时不加载的历史资源 |

`world/overworld/` 是 256×192 大世界完整主图的最末级目录，统一存放基础季、雨幕季、星熟季和长夜季的生成源图、运行时图与导入描述。主图只承担静态环境构图，不编码道路、水域、碰撞、资源、设施或存档状态。

## 归档规则

- 按运行时职责归档，不按生成批次、里程碑阶段或制作工具归档。
- 色键源图、最终运行图和 `.png.import` 保持同目录；运行时实际使用色键原图时必须在对应资产条目中说明。
- 新增 PNG 不得放在本目录根；`legacy/` 中的文件不得被代码或场景引用。
- 移动文件时同步更新 `res://` 引用、Godot 导入描述和本文路径，并完成仓库级旧路径扫描、资源导入与启动验证。
- 顶层分类与新增子域的维护入口见 [`assets/README.md`](../README.md)。
