# Luminfield 资源目录

`assets/` 按资源来源与运行时职责组织，避免把 NPC、设施、世界背景和 UI 图标混放在同一目录。

| 目录 | 用途 |
| --- | --- |
| `concepts/` | 概念草图与视觉方向参考，不由运行时直接加载 |
| `fonts/` | 项目字体 |
| `pixel/` | 手工维护的基础像素资源 |
| `generated/` | 为项目原创生成并经过检查的源图、运行时图与 Godot 导入描述 |

## 生成资源分类

`generated/` 先按运行时职责分类，再按系统或场景细分：

| 目录 | 收纳内容 |
| --- | --- |
| `activities/` | 战斗、钓鱼、采矿和各季节活动 |
| `animals/` | 共用畜牧资源，以及星羽鸡、月绒羊、露角兽各自的角色、设施与内景 |
| `characters/` | 玩家与 NPC 人物图集 |
| `farming/` | 作物、采集、果园和可放置农业物件 |
| `features/` | 委托、施工、经济主循环、邮件、加工机、关系、星灯和储物等功能点 |
| `locations/` | 小屋、村庄等可进入地点的背景与地标 |
| `ui/` | 物品、工具等跨场景 UI 图标 |
| `world/` | 家园、大世界探索与天气视觉 |
| `legacy/` | 当前运行时不加载、仅保留追溯价值的历史生成资源 |

`generated/world/overworld/` 专门保存 256×192 大世界的完整主图、季相源图与运行时图；它只承担静态环境外观，坐标、道路、水域、碰撞、资源、设施和存档仍由领域模型持有。

具体文件用途、图集布局与生成记录见 [generated/README.md](generated/README.md)。

## 归档规则

1. 以资源在运行时承担的职责分类，不按生成日期、开发阶段或制作工具建目录。
2. 色键源图、透明运行图和对应 `.png.import` 放在同一个最末级目录；同一功能的背景、实体图集与图标尽量相邻。
3. `generated/` 根目录只保留说明文档，新增 PNG 不得直接堆放在根目录。
4. 代码和场景只引用明确指定的运行时资源；保留作运行时色键材质输入的 `*_chroma.png` 必须在生成资源说明中写明。
5. `legacy/` 不得出现运行时引用。历史资源恢复使用前必须先迁入对应职责目录并重新完成接入检查。
6. 移动资源时必须同步更新全部 `res://` 引用、`.png.import` 的 `source_file` 与路径哈希，以及文档中的路径；随后执行旧路径扫描、C# 编译、核心测试、Godot 导入/启动和 `git diff --check`。
