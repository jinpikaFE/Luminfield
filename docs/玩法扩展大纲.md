# Luminfield 玩法扩展大纲

> 文档状态：产品规划与当前实现快照
>
> 版本：0.3
>
> 日期：2026-07-31
>
> 本文只定义后续要实现的玩法、优先级和验收目标，不代表这些功能已经完成。

## 1. 目标

把 Luminfield 从约 15 分钟的农场教程垂直切片，扩展成一款可以长期游玩的原创农场生活 RPG。

计划中的内容规模分三层：

- 近期可玩版：单个存档可以自然游玩 45–60 分钟，拥有完整的七日循环。
- 中期 Alpha：单个存档拥有约 8–12 小时内容，覆盖经营、村庄、钓鱼、矿洞和一个完整季节。
- 1.0 内容目标：主线约 25–35 小时，包含四季、多区域、关系、收集和长期建设；完成全部收集与关系内容可达到 50 小时以上。

核心体验不是简单堆叠小游戏，而是让每项活动互相提供资源和目标：

```text
农场生产
  → 出售、加工、烹饪
  → 获得资金和增益
  → 升级工具、建筑和背包
  → 解锁更远区域、矿洞和水域
  → 获得新品种、素材和故事
  → 反过来扩建农场并修复星灯网络
```

## 2. 参考方式与原创边界

《星露谷物语》值得参考的是系统覆盖面和循环组织：

- 非线性地选择种植、采集、钓鱼、采矿、战斗、制作、烹饪、送礼、任务和收集。
- 农业、采矿、采集、钓鱼、战斗形成并行成长路径。
- 季节和天气改变作物、鱼类、采集物、NPC 行为与节日。
- 关系、任务、节日和公共建设把赚钱循环连接到角色与世界变化。
- 动物、建筑、加工机和工具升级让农场从手工劳动逐步发展为可规划的生产系统。

Luminfield 只借鉴这些通用设计原则，不复制以下内容：

- 不复制角色、关系线、台词、任务文本和节日。
- 不复制地图布局、建筑外形、矿洞楼层、鱼类和作物名称。
- 不照搬物价、成长天数、掉落率、好感数值和配方。
- 不复制美术、动画、音效、音乐、代码和数据文件。
- 不使用“社区中心”等相同剧情目标，改为原创的六区域星灯修复主线。

- 日与日之间缺少足够变化，玩家没有理由连续游玩一周。

- 大世界以观光为主，区域内缺少事件、收集和长期解锁。
- 缺少技能、图鉴、成就和中长期主线。

## 4. 时间尺度与循环

### 4.1 每日循环

```text
查看天气、邮件和任务
  → 安排农田与动物
  → 选择村庄、采集、钓鱼或矿洞活动
  → 回家加工、制作、整理背包
  → 把商品放入星辉货箱
  → 睡眠并查看当日结算
```

每天必须至少出现一项可感知变化：

- 天气变化。
- 商店或 NPC 日程变化。
- 新任务、邮件或事件。
- 作物、加工机、动物或建筑进度变化。
- 区域采集物和矿洞内容刷新。

### 4.2 七日循环

- 每周固定一天举行暮光集市，出售轮换种子、家具和稀有配方。
- 委托板每日提供小任务，每周提供一个多阶段委托。
- NPC 每周有工作日、休息日和特殊地点安排。
- 商店库存、价格加成和世界事件按周轮换。
- 玩家应能在七天内完成一次“种植 → 加工 → 出售 → 投资”的小循环。

### 4.3 季节循环

采用四个原创季节，每季先规划为 14 天，降低独立游戏的内容制作压力，并让玩家更快体验变化：

| 稳定 ID | 中文名 | 视觉与玩法重点 |
| --- | --- | --- |
| `gleamrise` | 芽辉季 | 温和、多花草，适合基础作物和新手任务 |
| `rainveil` | 雨幕季 | 降雨频繁，水生作物、蘑菇和稀有鱼增加 |
| `starharvest` | 星熟季 | 高价值作物、果树和集市活动集中出现 |
| `longnight` | 长夜季 | 户外耕作受限，矿洞、动物、制作和关系内容更重要 |

当前阶段已实现由绝对日期纯推导的四季、季节日与年份，并把季节显示接入 HUD；
八名核心村民的日程已支持稳定天气/季节条件，并统一读取恢复后的实际当前天气。
季节作物、价格、环境换肤、节日和新存档字段仍属于后续阶段，不在本次日历能力内。

季节切换影响：

- 可购买和可种植作物。
- 野外采集物、鱼类和怪物。
- NPC 日程与对话。
- 环境色调、植被、光照和天气。
- 节日、生日与主线事件。
- 部分跨季作物、温室和魔法田地提供例外。

### 4.4 长期循环

- 修复六个区域的星灯台。
- 建设和升级家园农场。
- 提升五类技能并选择专精。
- 完成作物、鱼类、矿物、料理、工艺品和遗物图鉴。
- 推进 NPC 关系和个人故事。
- 解锁新的区域、移动方式和高阶资源。

## 5. 必须实现的玩法系统

### 5.1 深化农业

#### 基础内容

- 每个季节至少 8 种普通作物、2 种花卉、2 种稀有作物。
- 生长天数、浇水需求、重复收获、跨季能力和售价完全数据化。
- 作物拥有普通、莹润、星辉三个品质等级。
- 支持肥料、保水土、加速土和产量增幅。
- 支持洒水器、稻草人类保护设施和自动收集设施。
- 增加果树、灌木和可持续采收植物。
- 天气和地块类型可影响生长，但不应造成无法预见的永久损失。

#### Luminfield 特色

- 特定作物在月光、雨幕或星尘天气下产生“共鸣变种”。
- 相邻种植满足组合条件时，有小概率形成发光杂交作物。
- 六个区域分别提供一种土壤精华，用于解锁区域主题作物。

#### 验收目标

- 玩家在一个季节内至少能尝试三种不同经营策略。
- 农业升级能显著减少重复浇水，但不能让玩家完全失去规划空间。

### 5.2 资源采集与大世界

- 树木、水晶、药草、蘑菇、花朵和漂流物按日或按周再生。
- 每个区域拥有独立采集表、稀有资源和环境条件。
- 增加铲掘点、隐藏宝箱、遗迹机关和一次性探索事件。
- 支持工具等级：基础、青铜星纹、银辉、月晶。
- 解锁星门或星灯传送，减少后期重复跑图时间。
- 大世界事件包括流星坠落、萤火潮、浓雾、晶簇爆发和旅行商人。
- 地图记录地标、资源类型、NPC 和已发现秘密，但不直接显示全部答案。

#### 区域定位

| 区域 | 主要玩法 |
| --- | --- |
| 微光家园 | 农业、建筑、加工和动物 |
| 低语林地 | 木材、药草、蘑菇、昆虫与林地任务 |
| 星辉草甸 | 花卉、蜂蜜、动物饲料和季节活动 |
| 晶辉谷 | 矿石、水晶、矿洞入口和工具升级材料 |
| 月水湿地 | 钓鱼、水生作物、陷阱和天气事件 |
| 星落遗迹 | 遗物、战斗、高阶谜题和主线终局 |

### 5.3 经济、出售与商店

- 增加家园“星辉货箱”，睡眠后统一结算当日出售物。
- 结算画面按农业、采集、钓鱼、采矿、动物和加工分类。
- 保留即时出售商店，但价格低于货箱或只收特定类别。
- 商店拥有营业时间、休息日、季节库存和事件库存。
- 支持批量购买、批量出售和数量选择。
- 工具升级、背包扩容、建筑和配方构成主要资金回收点。
- 少量商品受每周需求影响，但不做难以理解的高频价格波动。
- 后期加入订单合约，为大量农产品提供稳定消耗出口。

### 5.4 制作、加工与烹饪

#### 制作

- 工作台支持批量制作并显示缺失材料。
- 第一批配方：木箱、路面、围栏、火把、洒水器、肥料、鱼饵和回程符石。
- 配方来源包括技能升级、NPC 关系、商店、任务和遗迹研究。
- 支持放置、旋转、拆除和可回收材料。

#### 加工

- 加工机从单队列扩展为地图实体，每台机器有独立输入和剩余时间。
- 第一批机器：蜜饯锅、药剂台、晶磨机、烘干架、蜂巢和织光机。
- 原料品质、加工时间和配方决定产物，不为每种物品写死逻辑。

#### 烹饪

- 小屋升级后解锁厨房和食材储藏。
- 料理恢复体力或生命，并提供时间有限的采集、钓鱼、速度、防御等增益。
- 食谱来自 NPC、节日、商店和探索。
- 同一种最优料理不能无限叠加，增益规则必须清楚可见。

### 5.5 建筑、农场布局与储物

- 可放置木箱、道路、围栏、灯具、装饰和生产设施。
- 支持网格预览、可放置/不可放置高亮和手柄操作。
- 建筑由村庄工匠负责施工，消耗资金、木材、石材和时间。
- 第一批建筑：仓库、鸡舍、畜棚、温室、工坊和星门基座。
- 小屋分两次升级，逐步解锁厨房、更多储物和装饰空间。
- 家具与装饰不提供强制属性，避免审美选择被数值绑架。
- 后期提供有限的农场区域扩建，而不是无限扩大地图。

### 5.6 动物饲养

#### 第一批动物

- 星羽鸡：产出星羽蛋。
- 月绒羊：产出月绒。
- 露角兽：产出凝露乳。

#### 核心规则

- 动物需要建筑、饲料、每日照料和可理解的心情反馈。
- 好感、心情、天气和食物影响产物品质。
- 动物有幼年和成年阶段，但不做永久死亡惩罚。
- 晴天可外出吃草，恶劣天气和长夜季留在室内。
- 产品可以直接出售，也可以加工为料理、织物和高价值工艺品。
- 自动喂食和自动收集作为中后期建筑升级。
- 繁育和稀有毛色放到动物系统稳定后的第二阶段。

### 5.7 村庄、NPC 日程与关系

#### 村庄基础

- 新增一张完整村庄地图和至少 6 个可进入建筑。
- Alpha 阶段先实现 8 名核心 NPC，1.0 扩展到 16–20 名。
- NPC 按时间、星期、季节、天气和事件运行日程。
- NPC 无法到达目标时必须安全回退，不能卡死或穿越碰撞。

#### 关系系统

- 交谈、送礼、完成委托和参加活动提升关系。
- 每名 NPC 有喜欢、普通和不喜欢的物品标签，不把所有物品逐个硬编码。
- 关系阶段解锁新对话、邮件、配方、场景事件和区域权限。
- 对话根据季节、天气、主线、最近任务和关系阶段变化。
- 关系衰减保持轻微或只在长期忽略时发生，避免强迫每日打卡。
- 恋爱、婚姻和家庭属于 1.0 后段内容，在普通友情故事完整后再做。

场景均兼容保存在 `schemaVersion: 1`。第一版关系奖励已通过次日星邮落地：
莉欧拉、塔维和奈米首次达到“可信朋友”后，分别寄出晶辉碎片、微光木与
星芽莓种子。当前仍采用时段间确定性换位，尚未加入格级行走寻路、天气/季节
分支、更多角色事件和其余 2 个建筑内部。莉欧拉的首条两阶段友情事件已经
落地：在档案馆内、使用“手”交谈、已认识莉欧拉且关系分别达到 25/60 点时
按顺序触发；第二阶段要求第一阶段在更早日期完成。事件复用现有档案馆与

按相同的 25/60 阈值和跨日顺序在月石工坊内落地；资格从事件定义读取人物、
场景、关系阈值与前置 ID，两名角色的事件链分别归一化，不互相过滤合法记录。

### 5.8 任务、邮件与事件

- 任务日志区分主线、角色故事、委托板、教程和节日任务。
- 每日委托从数据模板生成：交付、采集、种植、捕获、探索和击败目标。
- 随机任务只能从玩家已解锁的区域、物品和敌人中选择。
- 每周委托包含 2–4 个步骤，并给予配方、关系或建筑材料。
- 邮件系统用于发送剧情信息、礼物、商店通知和节日提醒。
- 地图事件具有时间、天气、关系和主线条件。
- 事件完成状态使用稳定 ID 存档，重复事件必须明确标记为可重复。

当前已落地第一版每日委托板：按天确定性轮换种植、采集和交付三类模板，接取
后由 HUD 追踪，睡眠后刷新；失败动作不计进度，交付结算原子扣物并发放微光币。
委托日期、稳定定义 ID、进度和领取状态使用 `schemaVersion: 1` 的加法字段
保存。捕获、探索、战斗、随机解锁过滤和每周多阶段委托仍属于后续增量。

第一版星邮也已落地：家园使用稳定 ID `starlight_mailbox` 的原创邮箱实体，
奈米欢迎信在相识后的次日投递；三名首批村民首次达到“可信朋友”后的次日
各投递一封一次性奖励邮件。星邮列表展示未读、正文、附件与领取结果，领取
使用背包原子容量规则，空间不足时附件仍保留。邮件只保存稳定定义 ID、送达日、
已读和已领取状态，作为 `schemaVersion: 1` 的加法投影兼容旧档并过滤未知 ID。

首条角色事件链也已落地：`liora_faded_return_route` 与
`liora_remembered_way_home` 各包含 3 页原创双语对话。资格判定读取交互前
的已认识状态、关系、当前场景、莉欧拉真实日程位置与所选“手”；事件对白
优先于普通对白，但仍走既有村民交谈入口。赠礼、错误工具、预览和首个对话页
均不会写完成状态，只有最后一页关闭才记录稳定事件 ID 与完成日期。旧存档
获得空列表，未知、重复、孤立和同日乱序记录会在读取时归一化。

第二条角色事件链使用 `tavi_cracked_moon_rune` 与 `tavi_mended_light`，
各包含 3 页原创双语对话。塔维必须按真实日程出现在月石工坊，玩家已认识他、
手持“手”且在交互前达到 25/60 点；第二阶段还要求第一阶段完成于更早日期。
事件资格已改为按 `CharacterEventDefinition` 数据驱动，莉欧拉回归与两条独立
NPC 事件链的未知、重复、孤立、同日乱序存档均由领域测试覆盖。

### 5.9 星灯修复主线

用原创的“六座星灯台”承担长期收集与世界修复目标：

1. 家园星灯：农业、加工和基础建设。
2. 林地星灯：采集、木材、药草和林地关系。
3. 草甸星灯：花卉、蜂蜜、动物与节日。
4. 晶谷星灯：矿物、工具升级和矿洞进度。
5. 湿地星灯：鱼类、水生作物和天气。
6. 遗迹星灯：遗物、战斗、关系与前五座星灯成果。

每座星灯由若干“星图节点”组成：

- 节点要求提交某一类别中的若干不同物品，而非固定照抄清单。
- 节点完成立即给予局部奖励，例如桥梁、传送点、新商店或区域净化。
- 整座星灯完成触发原创剧情、区域视觉变化和永久能力。
- 提供少量替代提交方案，让不同经营路线都能推进。

当前已落地第一座“林地守望星灯”：农业节点接受任意 3 种不同成熟作物，
材料节点接受 6 份微光木与 2 份晶辉碎片，工艺节点接受两种加工品和一个
星织储物箱。三个节点支持分批、按物品上限的原子提交；无可用物品时不产生
消耗。全部完成后地图实体切换为复苏状态，并永久把低语林地树木再生周期从
7 天缩短为 4 天。发现、逐物品贡献和奖励状态以稳定 ID 加法写入现有
`schemaVersion: 1`，旧存档、未知节点和超量贡献会安全归一化。

### 5.10 技能、经验与专精

五条主要技能：

| 技能 | 经验来源 | 中期专精示例 |
| --- | --- | --- |
| 耕作 | 收获、照料动物 | 丰收 / 牧养 |
| 采集 | 野外拾取、砍树、发现秘密 | 林守 / 寻星 |
| 晶矿 | 挖矿、冶炼、发现矿层 | 锻造 / 宝石 |
| 垂钓 | 捕鱼、陷阱和水域研究 | 猎潮 / 养殖 |
| 守夜 | 击败敌人、净化遗迹 | 护卫 / 咒刃 |

规则：

- 普通等级解锁配方、减少工具消耗或提升操作容错。
- 专精提供玩法方向，不出现明显唯一正确答案。
- 技能等级不直接替代玩家操作；钓鱼和战斗仍需参与。
- 五条技能达到上限后解锁“星脉共鸣”长期成长。
- 后期成长以横向能力、新配方和便利性为主，避免无限数值膨胀。

### 5.11 钓鱼与水域

- 使用钓竿蓄力抛投，落点距离影响稀有度和品质。
- 鱼类由区域、季节、时间、天气和水深共同决定。
- 上钩后进入短时控线小游戏，提供辅助模式和难度选项。
- 完美捕获提高品质或额外奖励，但普通成功也应稳定获得鱼。
- 支持鱼饵、浮标和钓竿升级。
- 支持蟹笼类被动捕获设施和鱼塘养殖。
- 稀有鱼承担图鉴和星灯节点，不作为主线唯一硬门槛。
- 垃圾可以回收为材料，减少纯失败体验。

第一批鱼类目标：

- 每个主要水域至少 5 种常见鱼。
- 每个季节至少 2 种条件鱼。
- 每个区域 1 种稀有鱼。
- Alpha 阶段总量约 24 种，1.0 扩展到 50 种以上。

### 5.12 矿洞与战斗

#### 辉晶地窟

- 矿洞使用小型房间组合生成，不直接复制固定百层结构。
- 每次进入生成若干连续区域，包含矿石、敌人、事件房和出口。
- 每 5 层建立一次稳定进度锚点，可从入口快速返回。
- 矿石层级、危险度和奖励随深度提升。
- 特殊房间包括晶簇、遗物、商人、恢复泉和挑战祭坛。

#### 战斗

- 支持近战武器、轻攻击、蓄力攻击、闪避和受击短暂无敌。
- 生命值与体力分离；体力用于劳动，生命用于战斗。
- 敌人需要清晰预警、攻击范围和掉落表。
- 第一批敌人控制在 6–8 种，每种具有可辨识行为。
- 装备包括武器、护符和一件星灵饰品，不做复杂随机词条海洋。
- 失败会提前结束当天并损失部分当日矿洞收益，但不删除核心工具和任务物品。
- 提供战斗伤害、敌人速度和闪避窗口辅助设置。

### 5.13 四季天气与环境

第一批天气：

- 晴朗：标准状态。
- 小雨：自动浇水，改变鱼类和 NPC 日程。
- 星尘风：提高采集物刷新，降低远处能见度。
- 雷暴：出现高价值能量材料和局部危险。
- 月雾：遗迹与稀有生物出现。
- 长夜雪：长夜季环境，影响移动和动物外出。

天气规则：

- 前一天可通过星象台或邮件查看预测。
- 天气影响必须提前可知，并通过 HUD、环境音和场景表现明确传达。
- 天气可以提供机会和变化，不应随机摧毁大量玩家资产。
- 特殊天气事件使用独立稳定 ID，便于任务和存档判断。

### 5.14 原创节日

每季先实现一个主节日，稳定后再增加次级活动：

| 季节 | 节日 | 核心玩法 |
| --- | --- | --- |
| 芽辉季 | 芽辉播种祭 | 合作布置花田、种子交换、限时种植挑战 |
| 雨幕季 | 流萤潮夜 | 夜间水域探索、灯船、稀有鱼与关系事件 |
| 星熟季 | 星熟集市 | 农产品展示、加工品评比、竞价订单 |
| 长夜季 | 长夜灯宴 | 料理贡献、礼物交换、主线星灯仪式 |

节日要求：

- 参加可选，不参加不能导致存档永久落后。
- 每个节日包含独立场景、对话、一个主要活动和一个节日商店。
- 节日奖励优先是装饰、配方、关系和便利能力，不提供不可替代的永久战力。
- 第二年可增加新对话、规则变化或高级奖励，避免完全重复。

### 5.15 图鉴、收藏与博物

- 图鉴分类：作物、采集物、鱼、矿物、遗物、料理、工艺品和敌人。
- 首次获得只负责登记，捐赠与星灯提交是独立状态。
- 星图档案馆展示遗物和区域故事，完成一组会改变馆内陈列。
- 支持物品来源、出现季节、时间、天气和已知地点提示。
- 未发现条目只显示轮廓，不直接泄露全部获得条件。
- 增加成就、统计和完成度，但不把全收集作为主线通关要求。

### 5.16 自定义与生活内容

- 玩家外观：肤色、发型、发色、服装、帽子和代称。
- 农场名称、角色名称和宠物选择。
- 家具放置、墙面、地板和照明。
- 服装与装饰主要通过节日、关系、制作和探索获得。
- 增加坐下、阅读、泡澡、演奏和与宠物互动等低压力动作。
- 支持截图模式，隐藏 HUD 并暂停时间。

### 5.17 辅助功能与体验优化

- 可调钓鱼小游戏难度。
- 可调战斗伤害、敌人速度和屏幕震动。
- 高对比目标提示和色盲辅助，不只依赖颜色表达状态。
- 字体大小、对话速度和自动推进选项。
- 按键重映射与手柄完整导航。
- 自动奔跑、工具目标锁定和长按连续操作。
- 存档保留最近若干天的备份。
- 可查看当前任务物品是否已拥有、已捐赠或仍需保留。

## 6. 支撑这些玩法的基础系统

实现内容前需要保持数据和状态边界清晰：

| 系统 | 职责 |
| --- | --- |
| `CalendarSystem` | 星期、季节、年份、生日和节日 |
| `WeatherSystem` | 今日/明日天气、区域天气和天气事件 |
| `SkillSystem` | 五类经验、等级、解锁和专精 |
| `VillageSystem / NpcScheduleSystem` | 已认识人物、NPC 日程、寻路、条件位置和安全回退 |
| `RelationshipSystem` | 好感、礼物、对话阶段和事件条件 |
| `QuestSystem` 扩展 | 多任务、模板委托、期限和奖励 |
| `RecipeSystem` | 制作、加工、烹饪配方与解锁来源 |
| `MachineSystem` | 多台地图机器的输入、时间和产物 |
| `BuildingSystem` | 放置、施工、升级和建筑容量 |
| `AnimalSystem` | 动物状态、喂养、心情、成长和产物 |
| `FishingSystem` | 抛投、鱼池、条件表、小游戏和品质 |
| `MineSystem` | 房间生成、深度、锚点、矿石和事件 |
| `CombatSystem` | 生命、武器、敌人、伤害、掉落和失败 |
| `CollectionSystem` | 发现、捐赠、星灯提交和完成度 |
| `EventSystem` | 剧情、关系、节日和世界事件条件 |

共同规则：

- 所有定义使用稳定 ID 和数据配置。
- 随机内容使用可保存或可复现的种子，避免读档后无限刷结果。
- HUD 和场景不保存唯一业务状态。
- 新增交互必须遵守根目录 `AGENTS.md` 的目标预览规则。
- 存档字段使用加法式迁移，重大结构变化再提升 `schemaVersion`。
- 每个系统先有纯逻辑测试，再接场景表现。

## 9. 暂不优先

以下功能不是当前扩充可玩时长的最高收益项：

- 多人联机。
- 婚姻、子女和复杂家庭系统。
- 模组 API。
- 云存档和跨平台账号。
- 大规模随机装备词条。
- 完整语音。
- 移动端和主机适配。
- 玩家自建关卡。

这些内容只有在单人核心循环、存档和内容生产流程稳定后再评估。

## 10. 每个新玩法的共同完成标准

一项玩法只有满足以下条件才算完成：

1. 有明确的玩家目标、输入和成功/失败反馈。
2. 有简体中文与英文文本。
3. 有数据定义和稳定 ID，不把内容写死在场景。
4. 有目标预览或交互高亮。
5. 无效操作不会错误消耗资源。
6. 状态可以正确保存、退出并恢复。
7. 有相关纯逻辑测试。
8. 在 macOS 实机检查像素表现、布局和输入。
9. 不破坏旧存档；如需迁移，有明确版本策略。
10. README、玩法大纲和 Personal Obsidian 记录同步更新。
